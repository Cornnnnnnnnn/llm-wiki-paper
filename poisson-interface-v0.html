11 / NEURAL REPRESENTATIONS離散を直す。表現を変える。

延伸：另一條路，
是讓函數直接表示兩側的解。

這兩篇以帶參數的 neural network 表示解，訓練它符合 PDE、邊界和介面條件。

DCSNN / HU ET AL., 2022 v3

用 label 分開兩側。

u ( x ) = U ( x , z ) , z = ± 1

兩個 slices 可有不同的解值。
以 loss（誤差指標）約束解值與通量跳躍。

z = −1、+1 標記所屬區域；此處將原文 φ、φaug 統一記為 u、U。
CUSP PINN / TSENG ET AL., 2023 v2

用 cusp 留住導數跳躍。

u ( x ) = U ( x , | ϕ ( x ) | )

解值自動連續，導數可以跳躍。
若解值也跳躍，另加 lifting network。

φ 是標示介面的函數：介面上 φ = 0，兩側分別取正、負；它不是 DCSNN 的解函數。
